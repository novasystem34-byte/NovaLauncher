# NovaLauncher
[![Donate](https://img.shields.io/badge/Donate-PayPal-00457C?logo=paypal)](https://paypal.me/Alaaabushamaa)
NovaLauncher هو lanzar/launcher خاص للألعاب على نظام Windows، مصمم ليكون خفيفًا على النظام ويمنح كل الموارد المتاحة للعبة أثناء التشغيل.

تم بناء المشروع باستخدام WPF على .NET 8، ويجمع بين مكتبة ألعابك، تتبع وقت اللعب، التشغيل داخل الخلفية، وسهولة إدارة كل لعبة من واجهة واحدة.

## المميزات

- إضافة ألعاب من ملفات .exe
- عرض مكتبة الألعاب بشكل أنيق وبطاقات قابلة للبحث
- فرز الألعاب حسب:
  - آخر تشغيل
  - أطول وقت لعب
  - الاسم أبجديًا
  - الأحدث إضافة
- تفضيل الألعاب (Favorites)
- إعادة تسمية اللعبة
- تعديل وسائط التشغيل (Launch Arguments)
- فتح مجلد اللعبة مباشرة
- إزالة اللعبة من المكتبة دون حذف الملف الأصلي
- تتبع مدة الجلسة وتسجيل وقت اللعب الإجمالي
- إخفاء التطبيق إلى شريط النظام أثناء تشغيل اللعبة لتوفير الموارد
- دعم التشغيل بواجهة عربية كاملة

## المتطلبات

- Windows 10 أو Windows 11
- بنية x64
- .NET 8 Desktop Runtime

## التثبيت

### الطريقة الأولى: الملف التنفيذي

1. حمل أحدث إصدار من صفحة Releases داخل المستودع.
2. شغل ملف التثبيت أو التطبيق المُصدَّر.
3. اتبع خطوات التثبيت الاعتيادية.

### الطريقة الثانية: البناء من المصدر

```powershell
git clone https://github.com/novasystem34-byte/NovaLauncher.git
cd NovaLauncher
dotnet restore
dotnet build -c Release
```

بعد البناء، سيتم إنتاج التطبيق في مجلد:

```text
bin\Release\net8.0-windows\win-x64\
```

## تشغيل المشروع

يمكن تشغيل التطبيق مباشرة من ملف التنفيذ بعد البناء أو التثبيت، أو من داخل Visual Studio باستخدام:

```powershell
dotnet run
```

ملاحظة: لأن المشروع يستهدف Windows WPF، يجب تشغيله على نظام Windows، وليس على Linux أو macOS.

## استخدام التطبيق

1. اضغط على زر "إضافة لعبة جديدة".
2. اختر ملف .exe الخاص باللعبة.
3. ستظهر اللعبة في المكتبة تلقائيًا.
4. يمكنك:
   - تشغيلها
   - إعادتها تسمية
   - تعديل خيارات التشغيل
   - فتح مجلد اللعبة
   - إزالتها من المكتبة

## ملاحظات مهمة

- التطبيق يدعم تشغيل لعبة واحدة في الوقت نفسه.
- أثناء التشغيل، يتم إخفاء النافذة إلى شريط النظام تلقائيًا.
- يتم حفظ بيانات كل لعبة داخل ملفات التكوين المحلية الخاصة بالتطبيق.
